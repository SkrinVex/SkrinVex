### ⚙️ Принципы разработки

* **Self-hosted first:** Софт работает на собственном железе/VPS, никакой искусственной привязки к сторонним SaaS.
* **Автономность и легковесность:** Монолитные бинарники, готовые Docker-образы и минимум хрупких внешних зависимостей.
* **Практическая польза:** Проекты создаются под конкретные сценарии и сразу готовы к эксплуатации.
